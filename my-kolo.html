Ця Політика конфіденційності описує, як додаток «My Kolo» збирає, використовує та захищає вашу інформацію.

1. Яку інформацію ми збираємо

  • Дані Google-акаунту: ім'я, email-адреса та фото профілю — отримуються через Google Sign-In для ідентифікації.
  • Дані профілю: інформація яку ви вносите в додаток.
  • Дані про місцевий бізнес та сервіси: інформація яку ви переглядаєте або додаєте.
  • Геолокація: точне місцезнаходження пристрою (GPS) — лише за вашою згодою, для показу локацій поруч на карті та визначення вашого району/міста.
  • Фото: знімки з камери або з галереї пристрою — коли ви додаєте фото локації, відгуку чи аватар профілю.
  • Push-токен пристрою: технічний ідентифікатор для надсилання сповіщень (можна вимкнути в налаштуваннях додатку).
  • Технічні дані про використання та збої: анонімна статистика взаємодії з додатком і звіти про помилки/збої — для покращення стабільності та якості сервісу.

2. Як ми використовуємо інформацію

  • Для надання персоналізованого доступу до місцевих сервісів та бізнесів.
  • Для ідентифікації вас у системі.
  • Для показу локацій поруч на карті та підбору контенту за вашим районом/містом.
  • Для надсилання push-сповіщень (нові відгуки, оновлення підписок тощо), якщо ви їх не вимкнули.
  • Для покращення якості сервісу та діагностики технічних проблем.

Ми не продаємо та не передаємо ваші дані третім особам з комерційною метою.

3. Зберігання даних

Всі дані зберігаються у хмарних сервісах Google Firebase (Firestore — база даних, Storage — фото та зображення), розташованих на серверах Google. Передача даних відбувається по захищеному протоколу HTTPS.

4. Сторонні сервіси

  • Google Firebase (Firestore, Storage, Authentication, Cloud Functions, Cloud Messaging) — база даних, зберігання файлів, авторизація та push-сповіщення. Політика конфіденційності Google
  • Google Sign-In — авторизація. Політика конфіденційності Google
  • Firebase Analytics — анонімна статистика використання додатку. Політика конфіденційності Google
  • Firebase Crashlytics — звіти про збої (технічна інформація про пристрій, без персональних даних). Політика конфіденційності Google
  • OpenStreetMap — карти для відображення локацій (без Google Maps).

5. Права користувача

  • Видалити свій акаунт та всі пов'язані дані через налаштування.
  • Надіслати запит на повне видалення: інструкція з видалення даних
